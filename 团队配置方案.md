# 空地协同系统 - 团队配置方案

## 🎯 项目概述

**目标**：实现无人机从小车起飞 → 搜索目标 → 发送坐标 → 小车移动 → 机械臂抓取 → 无人机返回的完整空地协同系统

## 📊 各角色工作内容详解

| 角色 | 主要工作 | 产出物 | 重要度 |
|------|----------|--------|--------|
| **嵌入式软件工程师** | PX4飞控配置、MAVROS对接、小车电机驱动、传感器驱动 | 飞控参数、底层驱动代码 | ⭐⭐⭐⭐⭐ |
| **视觉算法工程师** | YOLOv8训练、深度相机标定、手眼标定、视觉降落算法 | 检测模型、标定文件、定位算法 | ⭐⭐⭐⭐⭐ |
| **导航算法工程师** | SLAM建图、Nav2配置、路径规划、避障算法 | 地图、导航配置、规划算法 | ⭐⭐⭐⭐ |
| **后端/集成工程师** | ROS 2节点开发、Agent系统、任务状态机、通信架构 | 系统框架、API接口 | ⭐⭐⭐⭐ |
| **硬件工程师** | 电路设计、电源方案、传感器接线 | 电路图、接线方案 | ⭐⭐⭐ |
| **机械工程师** | 无人机组装、降落平台设计、机械臂安装 | 结构图、实体硬件 | ⭐⭐⭐ |
