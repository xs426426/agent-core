#### 3. 关键算法

```
┌─────────────────────────────────────────────────────────────┐
│                    关键算法模块                              │
└─────────────────────────────────────────────────────────────┘

【1. 目标搜索算法】
┌─────────────────────────────────────────┐
│         无人机搜索策略                    │
│                                          │
│  方式A：栅格扫描（覆盖式）               │
│  ┌─→─→─→─→─→─→─→─┐                      │
│  │               ↓                      │
│  │  ←─←─←─←─←─←─←┘                      │
│  ↓                                      │
│  └─→─→─→─→─→─→─→─┐                      │
│                  ↓                      │
│  适用：目标位置完全未知                  │
│                                          │
│  方式B：螺旋扫描（中心式）               │
│        ┌─→─┐                            │
│      ┌─┘   └─┐                          │
│      │   *   │  * = 起点                │
│      └─┐   ┌─┘                          │
│        └─←─┘                            │
│  适用：目标可能在某区域中心              │
│                                          │
│  方式C：AI引导搜索                       │
│  Agent分析场景后智能规划搜索路径         │
│  "桌子上可能有目标，先检查桌面"          │
│                                          │
└─────────────────────────────────────────┘

【2. 目标识别与定位】
┌─────────────────────────────────────────┐
│         目标识别流程                      │
│                                          │
│  RGB图像 ─→ YOLOv8检测 ─→ 边界框         │
│                              ↓           │
│  深度图像 ─────────────→ 深度值提取       │
│                              ↓           │
│  相机内参 ─────────────→ 3D坐标计算       │
│                              ↓           │
│  无人机位姿 ────────────→ 世界坐标转换    │
│                              ↓           │
│                      目标世界坐标         │
│                      (x, y, z)           │
│                                          │
│  公式：                                   │
│  X_world = R_drone * (K^-1 * [u,v,1] * d)│
│          + T_drone                       │
│                                          │
│  其中：                                   │
│  - K: 相机内参矩阵                        │
│  - d: 深度值                             │
│  - R_drone, T_drone: 无人机位姿          │
│                                          │
└─────────────────────────────────────────┘

【3. 小车路径规划】
┌─────────────────────────────────────────┐
│         导航流程                          │
│                                          │

│                     ↓                    │
│  激光雷达 ─→ 局部避障(DWA/TEB)           │
│                     ↓                    │
│  里程计 ────→ 位置跟踪                    │
│                     ↓                    │
│              运动控制(PID)               │
│                     ↓                    │
│              到达目标位置                 │
│                                          │
└─────────────────────────────────────────┘

【4. 机械臂抓取】
┌─────────────────────────────────────────┐
│         抓取流程                          │
│                                          │
│  目标位置 ─→ 手眼标定转换                 │
│                   ↓                      │
│  逆运动学 ←─ 末端目标位姿                 │
│      ↓                                   │
│  关节角度序列                             │
│      ↓                                   │
│  轨迹规划(MoveIt 2)                      │
│      ↓                                   │
│  运动执行 → 夹爪控制 → 抓取完成           │
│                                          │
│  【视觉伺服（精细调整）】                 │

│                                          │
└─────────────────────────────────────────┘

【5. 精准降落】
┌─────────────────────────────────────────┐
│         无人机降落到小车流程              │
│                                          │
│  1. 小车停稳，发送当前位置               │

│  5. 缓慢下降，持续修正                   │
│  6. 高度<0.5m时，切换超声波测距          │
│  7. 触地检测，关闭电机                   │
│  8. （可选）电磁锁固定                   │
│                                          │
│  关键技术：                              │
```
